# 서울 아파트 실거래가 데이터 분석

## 1. 프로젝트 개요

서울특별시 아파트 실거래가 데이터를 활용하여 지역구, 거래 시기, 전용면적, 층수에 따른 거래가격의 특징을 분석하는 프로젝트입니다.

Python과 Pandas를 이용하여 데이터를 수집·전처리하고, 기초 탐색적 데이터 분석(EDA)을 수행했습니다. 전처리 데이터와 분석 결과는 MariaDB에 저장했습니다.

향후 분석 결과를 바탕으로 가설 검증과 심화 분석을 진행할 예정입니다.

## 2. 프로젝트 목표

- 서울 25개 자치구별 아파트 거래가격 비교
- 연도별 및 월별 거래가격 변화 파악
- 전용면적과 거래가격의 관계 탐색
- 층수에 따른 거래가격 차이 분석
- 이상 수치 및 특이 거래의 영향 분석
- 가설 설정 및 데이터 기반 검증

## 4. 데이터 전처리

아파트 실거래가 데이터를 분석하기 위해 다음 작업을 수행했습니다.

- 거래 취소 데이터 제외
- 결측치 및 이상치 확인
- 계약연도 컬럼 생성
- 전용면적 구간 분류
- ㎡당 거래금액 계산
- 층수 구간 분류

**최종 분석 대상: 301,435건**

## 5. 기초 탐색적 데이터 분석 (EDA)

다음 6가지 항목에 대해 기초 통계 분석을 수행했습니다.

| 분석 항목 | 주요 분석 내용 |
|---|---|
| 지역구별 분석 | 평균 거래금액, 중앙값, 거래 건수 |
| 연도별 분석 | 연도별 거래가격 및 거래 건수 |
| 월별 분석 | 월별 거래가격 및 거래 건수 |
| 면적별 분석 | 전용면적 구간별 거래가격 |
| ㎡당 가격 분석 | 면적 구간별 ㎡당 거래가격 |
| 층수별 분석 | 층수 구간별 거래가격 |

## 6. 분석 가설

기초 분석을 바탕으로 다음과 같은 가설을 설정했습니다.

### 가설 1. 지역에 따른 가격 차이

**특정지역의 아파트들은 다른 지역보다 ㎡당 거래가격이 높을 것이다.**

- 지역구별 ㎡당 평균 및 중앙값 비교 예정

### 가설 2. 전용면적과 거래가격의 관계

**아파트 전용면적이 클수록 ㎡당 거래가격도 높을 것이다.**

- 면적 구간별 ㎡당 거래가격 비교 예정

### 가설 3. 층수와 거래가격의 관계

**아파트 층수가 높을수록 거래가격이 높을 것이다.**

- 층수별 거래가격 비교 및 지역·면적에 따른 차이 분석 예정

### 가설 4. 거래 시기에 따른 가격 변화

**최근 연도로 갈수록 서울 아파트의 거래가격이 상승했을 것이다.**

- 연도별 평균 및 중앙값 변화 비교 예정

### 가설 5. 초고가 거래의 영향

**일부 초고가 아파트 거래가 지역구별 평균 거래가격을 크게 높일 것이다.**

- 평균과 중앙값 차이 분석
- 상위 1% 고가 거래 제외 전후 비교 예정

※ 위 가설들은 아직 검증되지 않았으며, 향후 심화 분석을 통해 검증할 예정입니다.

## 7. 데이터베이스 구축

MariaDB의 `seoul_apartment` 데이터베이스에 전처리 데이터 및 분석 결과를 저장했습니다.

총 7개의 테이블로 구성했습니다.

| 테이블명 | 내용 |
|---|---|
| apartment_transactions | 전처리된 아파트 거래 데이터 |
| district_stats | 지역구별 분석 결과 |
| year_stats | 연도별 분석 결과 |
| monthly_stats | 월별 분석 결과 |
| area_stats | 면적별 분석 결과 |
| area_price_sqm_stats | ㎡당 가격 분석 결과 |
| floor_stats | 층수별 분석 결과 |
